# Брифи v6.0 — Android-приложение (Pixel 9a)

Полный редизайн по макету `Брифи v2.pdf` с «дышащим» градиентом, сторис «Производство» и интерактивным «Чек-листом», сохранением ссылок макетов, подтверждением оплаты недели, круговой диаграммой и плавными анимациями.

## Сборка APK на GitHub
1. Загрузи файлы из архива `Brifi_v6_AndroidProject.zip` в репозиторий на GitHub (проверь, что `.github/workflows/build-apk.yml` с точкой в начале).
2. Во вкладке **Actions** дождись зелёной галочки и скачай артефакт **Brifi-v6-APK**.

## Синхронизация обратно в Google Таблицу (обнови скрипт!)
В новой версии `google_apps_script.gs` добавлены **запись ссылки макета** (графа `Ссылка`) и **подтверждение оплаты недели**.
1. В Google Таблице открой **Расширения → Apps Script**, замени код на новый `google_apps_script.gs` и сохрани.
2. Нажми **Начать развертывание → Новое развертывание → Веб-приложение** (Запуск: *От моего имени*, Доступ: *Все*).
3. Скопируй URL и вставь его в **Профиль → Синхронизация с таблицей**.
